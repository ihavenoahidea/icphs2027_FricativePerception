# Supplement for ICPHS submission _Exploring the Dimensions of Fricative Perception_

The `fricative_stimuli_analysis.ipynb` and `icphs_analysis.ipynb` notebooks (and their corresponding .py files) recreate the figures and analyses from the paper.

The `data` directory holds the relevant data files, as well as an intermediate output from `fricative_stimuli_analysis.ipynb` stored as a `pkl`. The `src` directory contains some helper functions.

You can download this repository and copy its contents using the `uv` tool, or you can use the included `requirements.txt`.
